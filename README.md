# Notebooks-RI

Repositorio de prácticas y notebooks para Recuperación de Información (RI).

## Estructura del Proyecto

- **IB/**:
  - **BooleanSearch/**: Implementación y notebooks de Búsqueda Booleana ([`02_booleansearch.ipynb`](file:///IB/BooleanSearch/02_booleansearch.ipynb)).
  - **Machine Learning/**: Prácticas y modelos de ML aplicados a RI.
- **IIB/**: Prácticas del segundo bloque / bimestre.

## Archivos de Datos y Datasets

Por motivos de tamaño y rendimiento en Git, los archivos pesados de datasets en `IB/BooleanSearch/` están excluidos mediante [`.gitignore`](file:///.gitignore):
- Archivos comprimidos: `*.zip`, `*.tar`, `*.tar.*`, `*.gz` (por ejemplo `txt-files.tar.zip`, `txt-files.tar`)
- Archivos de texto extraídos: `txt-files/`, `*.txt`

> **Nota:** Si descargas o descomprimes los datasets localmente en la carpeta `IB/BooleanSearch/`, no serán rastreados por Git.
